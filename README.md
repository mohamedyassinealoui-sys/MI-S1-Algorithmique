# 🎓 MI-S1-Algorithmique | Plateforme Python d'apprentissage de l'algorithmique

Plateforme éducative interactive pour l'Algorithmique (MI S1), orientée apprentissage progressif de la pensée algorithmique et de Python.

## Fonctionnalités implémentées

- **Cours** organisés avec définitions, notations algorithmiques et flowcharts textuels.
- **Apprentissage Python** (variables, types, boucles, fonctions, structures de base).
- **Exercices** par niveau avec correction automatique et étapes détaillées.
- **Éditeur Python** pour écrire/exécuter du code avec explications d'erreurs.
- **Défis algorithmiques** avec validation automatique.
- **Tableau de bord étudiant** (progression, objectifs personnels, statistiques).
- **Interface bilingue** (Français principal + explications en Arabe).
- **Mode clair/sombre**.

## Démarrage

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Tests ciblés

```bash
python -m unittest discover -s tests -p "test_*.py"
```
